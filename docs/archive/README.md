# Archive — historical records

These documents are kept verbatim for provenance. They describe how the project was built
phase-by-phase and the reviews it passed; they are **not** the forward-facing design. For current
design and deployment, see [`docs/DESIGN.md`](../DESIGN.md) and [`docs/FORK.md`](../FORK.md).

| File | What it is |
|---|---|
| `DEVELOPMENT_PLAN.md` | The original phase-by-phase build plan (v4). The durable design has been distilled into `docs/DESIGN.md`; this retains the full phase DoDs, the build-time risk register, and the v2→v4 changelogs. |
| `GA_CHECKLIST.md` | The GA gate mapping against the P0–P8 build phases. Durable operational gates live in `FORK.md` / `RECOVERY.md` / `THREAT_MODEL.md`. |
| `OPEN_QUESTIONS.md` | The "wired + tested vs live-verified" tracking from the hardening branch, and the external-credential-wall notes. |
| `DEPLOY.md` | The original deploy runbook. Superseded by `docs/FORK.md` §4 (deploy) and §3 (executor install). |
| `CODE_REVIEW_2026-05-31.md` | Dated code-review audit trail (findings H-1, M-1…M-8, themes T-1…T-5). |
| `CODE_REVIEW_2026-06-01.md` | Dated Codex-findings remediation audit trail (CDX-1…CDX-8). |
